# GitHub OIDC shim

Cognito can federate to any OpenID Connect provider, but GitHub only speaks
OAuth 2.0. This service bridges the two: five Lambdas behind an API Gateway that
expose the OIDC endpoints Cognito expects (`/authorize`, `/token`, `/userinfo`,
`/.well-known/jwks.json`, `/.well-known/openid-configuration`) and translate them
into GitHub API calls.

Deployed by `infra/terraform/modules/github-oidc-shim`, which the persistent
stack instantiates. The Cognito GitHub identity provider federates against the
API's stage URL.

## Provenance

Vendored from [TimothyJones/github-cognito-openid-wrapper][upstream] at commit
`9f56e3a`, ISC licensed (see `LICENSE`). Changes made when vendoring:

- **The RSA signing key is runtime config, not a build artifact.** Upstream
  inlines `jwtRS256.key` into the bundle with `raw-loader`, so the built zip is
  the only copy of the private key. The previous deployment was adopted from a
  CloudFormation stack that way, and when access to the AWS account holding it
  was lost the key went with it and could not be rebuilt from source. The keys
  now arrive as `JWT_PRIVATE_KEY` and `JWT_PUBLIC_KEY`, generated by Terraform
  (`tls_private_key`), so this directory builds byte-for-byte from source and
  contains no secret.
- Dropped the `dist-web` express connector and its dependencies. Only the Lambda
  handlers are deployed.
- Dropped the Snyk, Pact, and release tooling.
- Production webpack build with source maps off, which cuts the artifact from
  14 MB to 4 MB.

Pulling upstream fixes means re-applying these on top.

## Build and test

```bash
npm ci
npm run build     # -> dist-lambda/ (gitignored; Terraform zips it)
npm test
```

From `infra/terraform`, `make shim-build` and `make shim-test` do the same, and
`make plan-persistent` / `make apply-persistent` depend on the build.

## Configuration

Set by Terraform as Lambda environment variables:

| Variable | Meaning |
|---|---|
| `GITHUB_CLIENT_ID` | GitHub OAuth app client ID |
| `GITHUB_CLIENT_SECRET` | GitHub OAuth app client secret, from SSM |
| `GITHUB_API_URL` | `https://api.github.com` |
| `GITHUB_LOGIN_URL` | `https://github.com` |
| `COGNITO_REDIRECT_URI` | Hosted-UI `…/oauth2/idpresponse` URL |
| `JWT_PRIVATE_KEY` | PEM RSA private key used to sign the `id_token` |
| `JWT_PUBLIC_KEY` | PEM RSA public key, published at the JWKS endpoint |

## Rotating the signing key

`terraform taint` the `tls_private_key.signing` resource in the module and
apply. Issued `id_token`s last an hour, so anyone mid-login has to retry.

## The GitHub OAuth app

Its callback URL must be the shim's `/token` endpoint on the current issuer.
The issuer URL is `terraform output github_oidc_issuer_url` from the persistent
stack, and it changes if the API Gateway is replaced.
